# Smart Attendance System

## AI Prompts Used During Project Development

The following prompts were used with ChatGPT during the development, debugging, testing, and documentation of the Smart Attendance System.

---

### 1. Project Planning

> Create a Smart Attendance System for a college using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB. The system should manage students, faculty, attendance records, and low-attendance alerts.

### 2. Backend Setup

> Help me create the backend for my Smart Attendance System using Node.js and Express.js with MongoDB. Explain the folder structure, database connection, models, controllers, and routes step by step.

### 3. MongoDB Connection

> Help me connect my Express.js backend to MongoDB Atlas using Mongoose and a .env file.

### 4. Student Registration

> Create a student registration system using Express.js and MongoDB. Student details should include name, USN, semester, division, gender, phone number, and email.

### 5. Student CRUD Operations

> Add functionality to view, edit, and delete existing student records from the Smart Attendance System.

### 6. Faculty Registration

> Create faculty registration functionality using Express.js and MongoDB. Store faculty name, faculty ID, email, and subject.

### 7. Faculty CRUD Operations

> Add functionality to view, edit, and delete existing faculty records from the Smart Attendance System.

### 8. Attendance Management

> Add attendance functionality where I can select a student, faculty, subject, date, and Present or Absent status, and store the attendance record in MongoDB.

### 9. Subject-Wise Attendance

> Calculate attendance subject-wise for each student using total classes and present classes.

### 10. Low Attendance

> Create a low-attendance feature that displays students whose subject-wise attendance is below 75%. Show the student name, USN, subject, total attendance, present classes, and attendance percentage.

### 11. Dashboard

> Create a dashboard showing total students, boys, girls, faculty, attendance records, and low-attendance records.

### 12. Dropdown Integration

> Load registered students and faculty members automatically into the attendance form dropdowns so they can be selected while marking attendance.

### 13. Existing Records After Refresh

> Make existing student and faculty records load automatically when the frontend page is refreshed, with Edit and Delete options available for existing records without adding them again.

### 14. Automatic Low Attendance Update

> Make the low-attendance section automatically update after attendance is added or edited.

### 15. Frontend Design

> Improve the frontend design of my Smart Attendance System to make it clean, professional, attractive, and easy to use without changing the existing functionality.

### 16. Debugging

> Help me debug my Smart Attendance System when attendance records are not displaying or storing correctly. Check the frontend, backend API, and MongoDB data flow step by step.

### 17. Algorithm

> Create a simple algorithm for my Smart Attendance System covering student management, faculty management, attendance, subject-wise attendance, low-attendance alerts, and dashboard statistics.

### 18. Flowchart

> Create a flowchart based exactly on the Smart Attendance System algorithm.

### 19. Project Documentation

> Create a professional README.md for my Smart Attendance System including the project title, problem statement, features, technologies, project structure, API endpoints, setup instructions, algorithm, flowchart, screenshots, AI prompts, future enhancements, and conclusion.

---

## Purpose of AI Assistance

ChatGPT was used as a learning and development assistant during the project.

It helped with:

* Understanding Node.js and Express.js.
* Understanding MongoDB and Mongoose.
* Creating REST APIs.
* Implementing CRUD operations.
* Debugging frontend and backend issues.
* Implementing subject-wise attendance calculation.
* Creating the low-attendance feature.
* Improving the frontend design.
* Preparing the algorithm and flowchart.
* Preparing project documentation.

The generated solutions were tested and integrated into the project during development.
